ALGORITHM ANALYSIS

Knapsack Algorithm Analyzer

An interactive tool for defining item weights, values, and a capacity, then solving the 0/1 Knapsack Problem.

Implements and compares Dynamic Programming, Greedy, Backtracking, and Branch & Bound, with analysis of correctness, computational complexity, execution performance, and scalability.

  • Step-by-step Dynamic Programming and DP table visualization
  • Runtime benchmarking and time/space complexity analysis
  • Optimal item selection and maximum-value calculation
  • Interactive results, execution history, and analytical reporting

Technical focus: Dynamic Programming, algorithms, optimization, algorithm analysis, and web development.
